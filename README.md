

# IcePad

This is a transparent macro keyboard featuring  maglev keyswitches  and an IPS display.



# Specification

|          | Basic                           | Pro                             |
| -------- | ------------------------------- | ------------------------------- |
| MCU      | ESP32-S3 , 8MB Flash            | ESP32-S3 , 16MB Flash，8MB Ram  |
| Dsiaplay | 2.8-inch ips  , 320x240 RGB     | 2.8-inch ips  , 320x240 RGB     |
| BUTTON   | Six magnetic maglev keyswitches | Six magnetic maglev keyswitches |
| MOTOR    | vibration motor                 | vibration motor                 |
| LED      | WS2812                          | WS2812                          |
| USB      | Type-C                          | Type-C                          |
| Speaker  | NS4168                          | NS4168                          |
| Mic      | ❌                               | PDM                             |
| Storage  | ❌                               | Micro SDCard                    |
